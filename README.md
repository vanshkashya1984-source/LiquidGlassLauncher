# LiquidGlassLauncher 🧊

A futuristic Android launcher inspired by the Liquid Glass design language.

## ✨ Features

- 🧊 Liquid Glass UI
- 🌫️ Glassmorphism and refraction effects
- 🔍 Glass search bar
- 🕐 Minimal clock and date
- 📱 Glass-style app dock
- ✨ Smooth Compose animations
- 🎨 Light, clean iOS-inspired interface
- 🚀 Designed for Android 14+

## 🛠️ Built With

- Kotlin
- Jetpack Compose
- Material 3
- Android SDK
- Kyant Backdrop

## 🎯 Goal

The goal of LiquidGlassLauncher is to create a modern Android home-screen experience inspired by Apple's latest translucent and glass-based UI design.

## 📦 Project Status

🚧 Currently in development.

The launcher UI and Liquid Glass effects are being built step by step.
